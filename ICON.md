# Tack App Icon — design spec

The icon is generated by Xcode from a single 1024×1024 PNG with no alpha channel.

## Design direction

**Concept:** a stylized sailboat heading upwind. The triangle/curve suggests forward motion, the gradient evokes dawn light catching a sail.

**Palette:**
- Background: deep navy `#0B0E12` with a subtle radial gradient
- Main sail: gradient accent `#5B8FF9 → #4169D5` (matching `TK.Palette.accent` and `accentDeep`)
- Highlight: pure white at the sail tip
- Drop shadow: subtle, never heavy

**Why a sail?**
- Continues the maritime family (Touchline, PitWall, Nautical — Enrique's universe).
- "Tack" is a sailing term (changing direction relative to the wind).
- Always points "up and to the right" = momentum.

**Constraints:**
- Round-cropped by iOS automatically. Critical content within radius 410px.
- Single 1024×1024 PNG, sRGB, no transparency.

## Files

Drop a `1024×1024` PNG named `AppIcon.png` into `Tack/Resources/Assets.xcassets/AppIcon.appiconset/` and Xcode does the rest.

## Alternative (fast)

If you don't want to commission a designer right now, drop in a solid navy square with the SF Symbol `figure.sailing` (white) centered. Code to insert:

```bash
# Use sips on macOS to scale a square SF Symbol screenshot
sips -z 1024 1024 source.png --out Tack/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png
```

We will iterate on the icon for v1.1 if needed — it doesn't block submission.
